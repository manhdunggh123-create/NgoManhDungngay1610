BÀI 2 - QUẢN LÝ KHO VÀ XUẤT BÁO CÁO

Yêu cầu: Visual Studio 2022 và .NET 8 SDK/Windows Desktop Runtime.
1. Giải nén ZIP.
2. Mở InventoryManagerApp.csproj bằng Visual Studio.
3. Chọn Build > Rebuild Solution.
4. Nhấn F5 để chạy.

Có sẵn: MenuStrip System/Tools; ToolStrip nút nhanh; StatusStrip tổng số mã hàng, tổng số lượng, tổng giá trị kho và thời gian; thêm/sửa/xóa/làm mới; chọn ảnh JPG/PNG/BMP; DataGridView chỉ hiện tên file ảnh; nhập/xuất CSV; lưu báo cáo JSON/CSV/TXT; mở JSON; hỏi xác nhận khi thoát.

CSV dùng tiêu đề: Id,Name,Category,Quantity,UnitPrice,ImagePath.
Ảnh được sao chép vào thư mục ProductImages cạnh file chạy. Dữ liệu sản phẩm nằm trong bộ nhớ cho tới khi lưu báo cáo.
